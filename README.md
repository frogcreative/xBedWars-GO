# NewBedwars-x

A BedWars game built with Dragonfly and Go. Players form teams, gather resources, buy gear, and try to destroy their opponents’ beds.

Features include arenas, resource generators, shops, team upgrades, scoreboards, respawning, and player elimination.

## Run

```bash
go get github.com/df-mc/dragonfly@master
go mod tidy
go run .
